# LandslideVL

Download the LandslideVL from our  [HuggingFace](https://huggingface.co/datasets/fluorites/LandslideVL). Your file structure will be like:
```
├── [Your Dataset Path]
    ├── JPEGImages
        ├── img_001.jpg
        ├── img_002.jpg
        └── ...
    ├── SegmentationClass
        ├── label_001.png
        ├── label_002.png
        └── ...
    ├── None
        ├── ima_xx1.png
        ├── img_xx2.png
        └── ...    
```
Then place the LandslideVL.csv file in the annotations folder.
